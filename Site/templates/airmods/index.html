Airmods - A Modable Airship

Airmods is a tool thats currently in development that will help Airship developers make modable games. Airship creators will be able to define modable properties and plugins to change how the game works and functions. The goal is to make full modablity from assets to code to allow a varity of user made content availible to users without ever leaving the game. We will utilize a in game mod editor similar to hytale and use server management to divide modded plays and vanila players and an in game mod selector.
