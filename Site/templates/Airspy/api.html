Airspy API Information

Below is the format for the airspy api for use in external apps

  • raynbo.games/airspy/api

    shows the format for the airspy api (you are here)

  • raynbo.games/airspy/api/games

    lists all tracked game ids

  • raynbo.games/airspy/api/games/{gameId}

    contains the information and stats of a game
